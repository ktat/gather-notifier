# For gather V2

Gather started Version 2.
When user is using gahter v2, current implementation is no use.

So, the following changes is needed.

Note that: For v1 users, user can choose v1 or v2 in extension setting.

## v2 domain

https://app.v2.gather.town/

## Calendar Notification

When calendar event  happens,
`User calendar events updated` is appeared in console.

## Wave Notification

When wave event happens, 
`[Violation] Forced reflow while executing JavaScript took 59ms` is appeared in console.

## Chat Notification

When chat event happens,
The message like `Tried to flush send metric for message dd71f548-b559-4aae-89f2-66ebf53814d1 but no pending metric found.` is appeared in console.

The part `dd71f548-b559-4aae-89f2-66ebf53814d1` is changed.

### Real Example

- Tried to flush send metric for message dd71f548-b559-4aae-89f2-66ebf53814d1 but no pending metric found.
- Tried to flush send metric for message 30dd4c0b-5c20-4882-bc0c-cbe169787ece but no pending metric found.
